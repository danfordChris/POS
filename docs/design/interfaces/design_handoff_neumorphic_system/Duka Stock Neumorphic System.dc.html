Assumptions & scope

Sample business is a fictional Tanzanian retailer, "Neema General Store", with realistic TZS pricing and Swahili-friendly copy lengths. Accent is teal (calm, trustworthy, distinct from typical indigo defaults). This first pass covers full foundations + component library, plus the highest-traffic screens: Web — Dashboard, Catalog, Sale detail. Mobile — Home, Catalog list, Sell. Use the controls above to flip theme, role and connectivity live across every screen below. Remaining routes (Stock, Sales list, Wingers, Members, Alerts, Reports, Settings, Support, and mobile Scan/Stock-in/Adjustment/Receipt/More) follow the same tokens and components — ask and I'll build them next.

Neumorphism accessibility guardrails
  • Primary actions are solid accent pills with AA-contrast labels — never shadow-only.
  • Body text, icons and table text always meet 4.5:1 / 3:1 against the surface — never embossed.
  • 2px accent focus ring with offset on every focusable element, always visible.
  • No pure white/black surfaces — shadows need a warm-grey light and desaturated charcoal dark base.
  • Destructive actions use danger color + a confirm step, never shadow alone.
